## Upload and duplicate rules

1. Duplicate an existing working Run Lighter instant-form ad so campaign, ad set, identity, tracking and form remain unchanged.
2. Replace the image, ad name, primary text and headline using the mappings above.
3. Confirm the Facebook Page and `run_lighter` Instagram identity are selected.
4. Confirm Feed, Stories and Reels previews do not crop the artwork headline or the R/L mark.
5. Check existing ad thumbnails before creation. Do not publish the same creative twice.
6. Publish each genuinely new ad to the existing ad set.
